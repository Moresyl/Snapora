Snapora 隐私说明与使用协议

生效日期：2026 年 9 月 18 日
软件名称：Snapora
作者：Mores

请在安装和使用 Snapora 前仔细阅读本说明。继续安装、启动或使用 Snapora，表示你已阅读、理解并同意本说明。如果你不同意其中任何内容，请选择“我不同意”并取消安装。

一、软件定位

1. Snapora 是一款用于屏幕截图、图片标注、贴图和本地剪贴板管理的 Windows 桌面软件。
2. Snapora 的核心功能在本机完成，不以在线账户作为使用前提。
3. Snapora 不要求用户提交姓名、手机号、身份证件、支付信息或其他身份资料。

二、软件可能处理的数据

1. 截图数据：当你执行截图操作时，软件会读取你授权的屏幕画面，并生成你选择的截图结果。
2. 标注数据：你在截图上添加的文字、线条、矩形、圆形、箭头、马赛克和模糊效果会保存在当前图片或本地贴图会话中。
3. 剪贴板数据：当你主动执行复制、贴图或剪贴板历史功能时，软件可能读取剪贴板中的图片、文本、HTML 或文件列表。
4. 贴图数据：你主动创建的贴图内容、位置、缩放比例、透明度和分组信息可能保存到本机，以便下次恢复。
5. 配置数据：包括快捷键、主题、颜色、线宽、保存目录、历史数量和其他软件设置。
6. 运行日志：日志可能包含启动时间、软件版本、操作结果、错误信息、系统版本和显示器基本信息，用于排查崩溃与功能问题。
7. 文件路径：当你主动保存、打开或导入文件时，软件会处理你选择的文件路径；软件不会扫描与你选择无关的文件。

三、数据保存位置

1. 截图文件保存在你在保存对话框或设置中选择的位置。
2. 配置文件保存在便携版配置文件或 Windows 应用数据目录中，具体位置取决于你的启动方式和配置。
3. 贴图会话、截图历史和剪贴板历史保存在本机应用数据目录中。
4. 运行日志保存在本机应用数据目录中，日志文件可能在达到大小限制后轮换保存。
5. 你可以通过软件设置、Windows 文件管理器或卸载软件删除这些本地数据。
6. 卸载程序默认删除安装目录中的程序文件；用户数据是否删除取决于你自行选择的清理方式，建议卸载前手动备份需要保留的截图和配置。

四、剪贴板权限与使用方式

1. Snapora 只在实现截图复制、贴图、剪贴板历史等功能时访问剪贴板。
2. 软件不会把剪贴板内容作为广告、画像或用户资料进行分析。
3. 如果你复制了密码、验证码、密钥或其他敏感内容，剪贴板历史功能可能将其保存在本机；使用敏感信息前请关闭或清空剪贴板历史。
4. 你可以在软件中清空剪贴板历史，也可以直接删除本地历史文件。

五、屏幕与窗口信息

1. 截图功能需要读取你主动选择的屏幕区域、窗口或显示器画面。
2. 软件可能读取显示器分辨率、缩放比例和窗口位置，以便准确显示选区和贴图。
3. 软件不会在后台持续录制屏幕，也不会在没有截图操作时保存屏幕画面。
4. 你应确保截图内容中不包含你无权公开的个人信息、商业秘密或第三方受保护内容。

六、网络与远程传输

1. 当前版本不会主动上传截图、剪贴板内容、配置文件或运行日志到远程服务器。
2. 当前版本不包含在线账户、广告追踪、行为画像或跨网站跟踪功能。
3. 如果你主动使用外部分享、命令行、浏览器、云盘或其他第三方程序，数据会按照相关第三方服务的规则处理。
4. 将来如果增加在线更新、网络服务或远程功能，软件将通过版本说明或新的隐私说明告知相关变化。

七、第三方组件

1. Snapora 使用 Qt 等第三方软件组件运行图形界面和系统功能。
2. 第三方组件可能有各自的许可证和版权声明，这些声明不改变本说明对 Snapora 自身数据处理行为的描述。
3. Snapora 不会因使用第三方组件而获得你剪贴板、屏幕或文件内容的额外所有权。

八、数据安全

1. Snapora 尽力使用系统提供的本地文件接口保存数据，但不能保证用户设备、磁盘、系统账户或第三方软件绝对安全。
2. 请使用受保护的 Windows 用户账户，并避免把敏感截图保存到公开共享目录。
3. 如果你将配置、日志、截图或历史目录复制到其他设备，相关数据安全由你负责。
4. 发现异常、误删或数据损坏时，请先停止继续覆盖原目录，并保留相关日志以便排查。

九、用户控制权

1. 你可以选择是否使用截图、贴图、剪贴板历史、自动备份和日志功能。
2. 你可以修改保存目录、历史数量、快捷键和其他选项。
3. 你可以随时清空历史、删除截图、删除配置和日志，或卸载 Snapora。
4. 你可以通过作者提供的联系方式反馈隐私问题、删除请求或安全问题。

十、未成年人使用

1. Snapora 不针对未成年人收集身份信息，也不以未成年人为特定服务对象。
2. 未成年人使用本软件时，应在监护人指导下进行，并注意截图和剪贴板中可能包含的敏感信息。

十一、协议更新

1. 当软件功能、数据处理方式或适用法律发生变化时，本说明可能更新。
2. 更新后的说明会随安装包发布，并显示新的生效日期。
3. 如果你不同意更新后的内容，可以停止使用并卸载 Snapora。
