Snapora Privacy Notice and Terms of Use
(English reference translation. The Chinese original that follows this translation is the binding version.)

Please read this notice carefully before installing or using Snapora. By continuing to install, launch or use Snapora you confirm that you have read, understood and agree to it. If you do not agree with any part of it, choose "I do not accept" and cancel the installation.

1. What Snapora is

1. Snapora is a Windows desktop application for taking screenshots, annotating images, pinning images to the screen and managing the local clipboard.
2. Its core features run entirely on your computer; no online account is required.
3. Snapora does not ask you for your name, phone number, identity documents, payment details or any other identity information.

2. Data the software may process

1. Screenshot data: when you take a screenshot, the software reads the screen area you authorize and produces the capture you chose.
2. Annotation data: the text, lines, rectangles, ellipses, arrows, mosaic and blur effects you add to a screenshot are stored in the current image or in the local pinned-image session.
3. Clipboard data: when you use the copy, pin or clipboard-history features, the software may read images, text, HTML or file lists from the clipboard.
4. Pinned-image data: the content, position, zoom level, opacity and grouping of the images you pin may be saved on this computer so they can be restored next time.
5. Settings: hotkeys, theme, colors, line width, save folder, history size and other program settings.
6. Logs: logs may contain the start time, software version, operation results, error messages, operating system version and basic display information, and are used to diagnose crashes and feature problems.
7. File paths: when you save, open or import a file, the software handles the path you chose; it does not scan files unrelated to your choice.

3. Where data is stored

1. Screenshot files are saved to the location you choose in the save dialog or in the settings.
2. Settings are stored in the portable configuration file or in the Windows application data folder, depending on how you start and configure the program.
3. Pinned-image sessions, screenshot history and clipboard history are stored in the local application data folder.
4. Logs are stored in the local application data folder and may be rotated once they reach a size limit.
5. You can delete this local data through the program settings, Windows File Explorer, or by uninstalling the software.
6. The uninstaller removes the program files in the installation folder by default; whether user data is removed depends on the clean-up you choose. Back up the screenshots and settings you want to keep before uninstalling.

4. Clipboard access

1. Snapora accesses the clipboard only to provide features such as copying screenshots, pinning and clipboard history.
2. Clipboard content is never analyzed for advertising, profiling or user data.
3. If you copy passwords, verification codes, keys or other sensitive content, the clipboard-history feature may store it on this computer; turn off or clear the clipboard history before handling sensitive information.
4. You can clear the clipboard history inside the program or delete the local history files directly.

5. Screen and window information

1. The screenshot feature reads the screen area, window or display you actively select.
2. The software may read display resolution, scaling and window positions in order to show selections and pinned images accurately.
3. The software does not record the screen in the background and does not save screen content when no screenshot is being taken.
4. You are responsible for making sure that your screenshots do not contain personal information, trade secrets or third-party protected content that you are not entitled to disclose.

6. Network and remote transfer

1. The current version does not upload screenshots, clipboard content, settings or logs to any remote server.
2. The current version contains no online accounts, advertising tracking, behavioral profiling or cross-site tracking.
3. If you use external sharing, the command line, a browser, cloud storage or other third-party programs, your data is handled under the rules of those third-party services.
4. If online updates, network services or remote features are added in the future, the change will be announced in the release notes or in an updated privacy notice.

7. Third-party components

1. Snapora uses third-party software components such as Qt for its user interface and system features.
2. Those components may have their own licenses and copyright notices; they do not change how this notice describes Snapora's own data handling.
3. Using third-party components gives Snapora no additional rights over your clipboard, screen or file content.

8. Data security

1. Snapora does its best to store data through the local file interfaces provided by the operating system, but cannot guarantee the absolute security of your device, disks, user account or third-party software.
2. Use a protected Windows user account and avoid saving sensitive screenshots to publicly shared folders.
3. If you copy settings, logs, screenshots or history folders to other devices, you are responsible for the security of that data.
4. If you notice anomalies, accidental deletion or data corruption, stop overwriting the original folder and keep the relevant logs for troubleshooting.

9. Your controls

1. You decide whether to use the screenshot, pin, clipboard history, automatic backup and logging features.
2. You can change the save folder, history size, hotkeys and other options.
3. You can clear the history, delete screenshots, delete settings and logs, or uninstall Snapora at any time.
4. You can report privacy concerns, deletion requests or security issues through the author's contact details.

10. Use by minors

1. Snapora does not collect identity information from minors and is not specifically aimed at minors.
2. Minors should use the software under the guidance of a guardian and be aware of the sensitive information that screenshots and the clipboard may contain.

11. Changes to this notice

1. This notice may be updated when the software's features, its data handling or the applicable law change.
2. The updated notice ships with the installer and shows a new effective date.
3. If you do not agree with the updated notice, you may stop using and uninstall Snapora.

一、软件定位

1. Snapora 是一款用于屏幕截图、图片标注、贴图和本地剪贴板管理的 Windows 桌面软件。
2. Snapora 的核心功能在本机完成，不以在线账户作为使用前提。
3. Snapora 不要求用户提交姓名、手机号、身份证件、支付信息或其他身份资料。

二、软件可能处理的数据

1. 截图数据：当你执行截图操作时，软件会读取你授权的屏幕画面，并生成你选择的截图结果。
2. 标注数据：你在截图上添加的文字、线条、矩形、圆形、箭头、马赛克和模糊效果会保存在当前图片或本地贴图会话中。
3. 剪贴板数据：当你主动执行复制、贴图或剪贴板历史功能时，软件可能读取剪贴板中的图片、文本、HTML 或文件列表。
4. 贴图数据：你主动创建的贴图内容、位置、缩放比例、透明度和分组信息可能保存到本机，以便下次恢复。
5. 配置数据：包括快捷键、主题、颜色、线宽、保存目录、历史数量和其他软件设置。
6. 运行日志：日志可能包含启动时间、软件版本、操作结果、错误信息、系统版本和显示器基本信息，用于排查崩溃与功能问题。
7. 文件路径：当你主动保存、打开或导入文件时，软件会处理你选择的文件路径；软件不会扫描与你选择无关的文件。

三、数据保存位置

1. 截图文件保存在你在保存对话框或设置中选择的位置。
2. 配置文件保存在便携版配置文件或 Windows 应用数据目录中，具体位置取决于你的启动方式和配置。
3. 贴图会话、截图历史和剪贴板历史保存在本机应用数据目录中。
4. 运行日志保存在本机应用数据目录中，日志文件可能在达到大小限制后轮换保存。
5. 你可以通过软件设置、Windows 文件管理器或卸载软件删除这些本地数据。
6. 卸载程序默认删除安装目录中的程序文件；用户数据是否删除取决于你自行选择的清理方式，建议卸载前手动备份需要保留的截图和配置。

四、剪贴板权限与使用方式

1. Snapora 只在实现截图复制、贴图、剪贴板历史等功能时访问剪贴板。
2. 软件不会把剪贴板内容作为广告、画像或用户资料进行分析。
3. 如果你复制了密码、验证码、密钥或其他敏感内容，剪贴板历史功能可能将其保存在本机；使用敏感信息前请关闭或清空剪贴板历史。
4. 你可以在软件中清空剪贴板历史，也可以直接删除本地历史文件。

五、屏幕与窗口信息

1. 截图功能需要读取你主动选择的屏幕区域、窗口或显示器画面。
2. 软件可能读取显示器分辨率、缩放比例和窗口位置，以便准确显示选区和贴图。
3. 软件不会在后台持续录制屏幕，也不会在没有截图操作时保存屏幕画面。
4. 你应确保截图内容中不包含你无权公开的个人信息、商业秘密或第三方受保护内容。

六、网络与远程传输

1. 当前版本不会主动上传截图、剪贴板内容、配置文件或运行日志到远程服务器。
2. 当前版本不包含在线账户、广告追踪、行为画像或跨网站跟踪功能。
3. 如果你主动使用外部分享、命令行、浏览器、云盘或其他第三方程序，数据会按照相关第三方服务的规则处理。
